# 🎬 GetWords · 项目规划

> 纯血鸿蒙（HarmonyOS NEXT / ArkTS）**英语学习工具集**，平板优先、手机/电脑自适应，**个人自用**。
> 工程在 [`GetWords/`](./GetWords)。本文件记录项目情况、需求、设计原则与工作计划，持续更新。

---

## 一、定位与设计原则 🧭

| 原则 | 说明 |
|---|---|
| 🏠 个人自用 · 内容驱动 | 从「你看的内容（YouTube 字幕等）」里收集生词，而非背预制词表；在线抓取涉及版权/ToS，不上架商店 |
| 📱 多设备自适应 | **手机 / 平板 / 电脑**都要好看：内容最大宽度居中、断点列数、百分比+layoutWeight |
| 🧠 复习有方法论 | 借鉴 **SM‑2 遗忘曲线**算法；但**客观测试**（选择题/拼写）判对错，**不自评**、**不做成 Anki** |
| 🎨 UI 原创 | 借鉴 百词斩 / 不背单词 的**交互思路**，UI 自己实现，不照搬素材 |
| 🗄️ 数据后置 | 现阶段全 **mock**；真实词库/词典数据后续导入，接 `relationalStore` |

## 四、技术栈 / 架构 🛠️

- **平台**：HarmonyOS NEXT，目标/兼容/编译均 `6.1.1(24)`（纯血鸿蒙，不向下兼容）
- **语言/UI**：ArkTS + ArkUI（声明式）
- **自适应**：最大宽度居中 + 断点(sm/md/lg)列数 + `GridRow/GridCol`（规划统一）
- **数据**：现 mock；规划 `@ohos.data.relationalStore`（词条+复习流水，建索引、分页）；设置用 `PersistentStorage`
- **AI**：DeepSeek（`deepseek-chat`）翻译/查词/分级
- **PDF**：HTML 排版 → ArkWeb `createPdf`
- **手写**：系统手写输入法（不自造识别引擎）

